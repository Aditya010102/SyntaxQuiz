# 🚀 SyntaxQuiz

A modern Full Stack Quiz Platform built with Angular, Flask, and MySQL.

## ✨ Features

- JWT Authentication
- Google Sign-In
- Role-Based Authorization
- Admin Dashboard
- Student Dashboard
- Quiz Engine
- Leaderboard
- Favorites
- Profile Management
- Analytics Dashboard
- Responsive Design

---

## 🛠 Tech Stack

### Frontend
- Angular 21
- TypeScript
- HTML5
- CSS3

### Backend
- Flask
- SQLAlchemy
- Flask JWT Extended

### Database
- MySQL

### Authentication
- JWT
- Google OAuth

## 🚀 Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend

```bash
cd frontend
npm install
ng serve
```

---

## 🔐 Environment Variables

Create a `.env` file.

```env
DATABASE_URL=

JWT_SECRET_KEY=

GOOGLE_CLIENT_ID=
```
